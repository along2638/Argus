系统概述

Argus 是一个智能监控告警系统，支持 RTSP/RTMP 视频流接入、YOLOv11 多目标检测、Redis 去重、MySQL 持久化、MinIO 图片存储。系统提供 Web 管理界面，支持实时流处理、图片检测、手动标注、安全帽检测等功能。

📌 本说明基于当前开发环境配置，如使用 Docker 部署请参考对应章节。

快速安装

方式一：本地安装

# 1. 克隆项目
git clone <repo-url>
cd Argus

# 2. 创建虚拟环境
python -m venv .venv
.venv\Scripts\activate  # Windows
# source .venv/bin/activate  # Linux/Mac

# 3. 安装依赖
pip install -e ".[dev]"

# 4. 配置环境变量
cp .env.example .env
# 编辑 .env 填写数据库、Redis、MinIO 连接信息

# 5. 数据库迁移
alembic upgrade head

# 6. 启动服务
uvicorn app.main:app --host 0.0.0.0 --port 8000 --reload

方式二：Docker 部署

# 一键启动（API + Worker + Redis + MySQL + MinIO）
docker compose up -d

# 查看日志
docker compose logs -f

# 停止服务
docker compose down
✅ Docker 部署自动包含所有基础设施服务，无需单独安装 MySQL/Redis/MinIO。

常见问题

Q: GPU 不可用怎么办？

系统会自动回退到 CPU 推理。检测速度约 200ms/张（CPU），对于实时监控场景可接受。如需 GPU 加速，请升级到 RTX 2060 及以上显卡。

Q: 上传图片检测卡住？

已修复：检测器现在强制使用 CPU，跳过 CUDA 初始化，避免挂起。如仍有问题，检查 app/core/detector.py 中的 Provider 配置。

Q: 安全帽检测不准？

系统使用统一检测方法：通用模型检测人 + 安全帽模型检测帽子，差集 = 未戴帽。有人时才跑安全帽模型，无人时自动跳过。头部不在画面内时跳过判定，避免误报。

Q: 如何添加新的检测模型？

1. 在 app/config.py 添加模型路径和 CLASS_MAPPING
2. 在 app/core/detector.py 的 _models 字典中注册
3. 将 ONNX 模型文件放入 models/onnx/ 目录

Q: 视频流检测太慢？

系统已优化：自适应采样（连续无人时检测间隔从 1 秒逐渐延长至 60 秒）、模型预热、数据库连接池优化。如仍慢，检查 GPU 是否可用或降低模型分辨率。

技术栈总览

后端

  • Web: FastAPI + Uvicorn
  • ORM: SQLAlchemy 2.0 + aiomysql
  • 检测: YOLOv11 ONNX (CPU/GPU)
  • 流处理: PyAV (RTSP/RTMP)
  • 追踪: ByteTrack (supervision)
  • 队列: ARQ + Redis
  • 存储: MinIO
  • 认证: PBKDF2-SHA256 + JWT

前端

  • 框架: 原生 HTML/CSS/JS
  • 样式: CSS Variables 主题系统
  • 字体: DM Sans + JetBrains Mono
  • 图表: 自定义 SVG 图表
  • 实时通信: WebSocket 告警推送

基础设施

  • 数据库: MySQL 8.0
  • 缓存: Redis 7
  • 存储: MinIO
  • 容器: Docker Compose
